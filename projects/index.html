Friends - 尋找志同道合的夥伴

作品連結

專案介紹 Link to heading

這是一個基於 Vue + SpringBoot 的前後端分離開發專案，
協助使用者找到興趣相符的夥伴，共同建立 side project。
主要功能包括：

  • 透過標籤查詢使用者
  • 推薦相似夥伴
  • 建立與加入隊伍

技術棧 Link to heading

  • 前端：Vue
  • 後端：SpringBoot + SpringMVC + Mybatis Plus
  • 資料庫：MySQL
  • 快取：Redis

專案重點與亮點 Link to heading

  1. 善用 Java 8 Stream API 與 Lambda 簡化程式碼
    在處理「關聯隊伍清單中已加入成員」等較複雜的集合操作時，使用 Java 8 Stream API 與 Lambda，能讓程式碼更具可讀性與維護性。

  2. Redisson 分散式鎖確保操作唯一性
    為避免同一使用者重複加入隊伍或重複建立隊伍，透過 Redisson 分散式鎖實現操作的唯一性，
    確保每次請求都能得到正確且一致的結果。

  3. 定時快取預熱提升首頁載入速度
    透過 Spring Scheduler 進行定時快取預熱，並運用分散式鎖機制避免多台機器同時執行定時任務，
    顯著縮短系統首次使用時的等待時間。

  4. 自訂線程池與 CompletableFuture 進行併發處理
    針對大批量資料庫匯入需求，搭配自訂線程池與 CompletableFuture 實現高效併發。

    • 實測顯示，匯入 10 萬筆 資料的時間由 8 秒 縮短至 4.8 秒，
      效能提升約 67%。
