Friends - 尋找志同道合的夥伴

項目連結

項目介紹 Link to heading

這是一個基於 Vue + SpringBoot 的前後端分離開發項目，
協助使用者找到興趣相符的夥伴，共同建立 side project。
主要功能包括：

  • 推薦相似夥伴
  • 透過標籤查詢使用者
  • 建立與加入隊伍

項目架構 Link to heading

技術棧 Link to heading

  • 前端：Vue
  • 後端：SpringBoot + SpringMVC + Mybatis Plus
  • 資料庫：MySQL
  • 快取：Redis
  • 連線：HTTPS + Nginx + Session
  • 雲端：AWS S3 + AWS EC2
  • 開發工具：Git + GitHub

項目重點與亮點 Link to heading

  1. 善用 Java 8 Stream API 與 Lambda 簡化程式碼

在處理「關聯隊伍清單中已加入成員」等複雜的集合操作時，利用 Java 8 Stream API 與 Lambda。 使程式碼簡潔、易讀，並提升維護性。

  1. Redisson 分散式鎖確保操作唯一性

避免同一使用者重複加入隊伍或重複建立隊伍。 使用 Redisson 分散式鎖，確保每次請求的操作唯一性與正確性。

  1. 定時快取預熱提升首頁載入速度

透過 Spring Scheduler 進行定時快取預熱。 結合分散式鎖，防止多台伺服器同時執行定時任務，縮短首次使用等待時間，提升使用體驗。

  1. 自訂線程池與 CompletableFuture 進行併發處理

為應對大批量資料庫匯入需求，結合自訂線程池與 CompletableFuture 提高併發效率。 測試結果顯示：匯入 10 萬筆資料，時間從 8 秒縮短至 4.8 秒，效能提升約 67%。
